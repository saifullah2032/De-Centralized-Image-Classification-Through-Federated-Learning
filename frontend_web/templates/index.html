What is Federated Learning?

Federated Learning is a distributed machine learning approach where data never leaves local devices. Instead of centralizing data, we bring the model to the data, train locally, and only share model updates (weights) with the server.

Privacy First

Raw data stays on your device

Collaborative

Train together without sharing data

Compliant

GDPR & HIPAA ready

How FedAvg Algorithm Works
1

Server broadcasts

Global model sent to clients

2

Clients train locally

Each client updates on local data

3

Send updates back

Only weights shared, no raw data

4

Server aggregates

w = Σ(nₖ/n)·wₖ

Formula: wglobal = Σ(nk/n) · wk
Where nk = data samples on client k, wk = client k's weights
