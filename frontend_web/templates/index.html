How Federated Learning Works

1
Initialize

Server broadcasts global model to all participating client nodes

2
Local Training

Each client trains on local data without sharing raw information

3
Share Updates

Clients send encrypted model weights back to central server

4
Aggregate

Server combines updates using FedAvg to improve global model

FedAvg Algorithm
wglobal = Σ (nk / n) × wk

Weighted average ensures larger datasets have proportional influence on the global model
