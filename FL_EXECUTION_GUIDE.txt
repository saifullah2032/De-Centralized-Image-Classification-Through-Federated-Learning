================================================================================
FEDERATED LEARNING CLIENT-SERVER SETUP GUIDE
================================================================================

This guide explains what to expect and what to look for when running the
federated learning system with 3 terminals.

================================================================================
EXECUTION ORDER
================================================================================

1. START SERVER FIRST (Terminal 1)
2. START CLIENT 0 (Terminal 2) - will connect and wait
3. START CLIENT 1 (Terminal 3) - training begins automatically when both connect

================================================================================
TERMINAL 1: SERVER - WHAT TO LOOK FOR
================================================================================

PHASE 1: Server Initialization
-------------------------------
✓ Configuration loaded
✓ "FEDERATED LEARNING SERVER" banner displayed
✓ Server address: 0.0.0.0:8080 (or localhost:8080)
✓ Training rounds: 3
✓ Min clients: 2
✓ Loading test dataset (10,000 samples)
✓ "Waiting for 2 clients to connect..."

STATUS: Server is READY and LISTENING

PHASE 2: Client Connection
---------------------------
When Client 0 connects:
✓ You'll see: "Flower ECE: gRPC server running..."
✓ Message: "Requesting initial parameters from one random client"

When Client 1 connects:
✓ Server detects 2 clients are ready
✓ Training begins automatically

PHASE 3: Training Rounds (x3)
------------------------------
For EACH round (1, 2, 3), you'll see:

✓ "=== ROUND X/3 ==="
✓ "Configuring round X..."
✓ "Fit round X received Y results"
✓ Aggregating model weights from clients
✓ Evaluating global model on test set
✓ Model saved to: models/model_round_X.h5
✓ Accuracy and loss metrics displayed

EXAMPLE OUTPUT PER ROUND:
--------------------------
=== ROUND 1/3 ===
Fit round 1 received 2 results
Aggregating weights from 2 clients...
Global model accuracy: 45.23%
Global model loss: 1.5234
Model saved: models/model_round_1.h5

PHASE 4: Completion
-------------------
After Round 3:
✓ "TRAINING COMPLETED SUCCESSFULLY!"
✓ Final model saved: models/global_model.h5
✓ Training history saved: models/model_history.json
✓ Summary statistics displayed

================================================================================
TERMINAL 2 & 3: CLIENTS - WHAT TO LOOK FOR
================================================================================

PHASE 1: Client Initialization
-------------------------------
✓ Configuration loaded
✓ "STARTING FEDERATED LEARNING CLIENT X" banner
✓ Server address: localhost:8080
✓ Client ID: 0 (or 1)
✓ Total clients: 2

PHASE 2: Data Loading
----------------------
✓ Loading CIFAR-10 dataset (50,000 train, 10,000 test)
✓ Partitioning data for 2 clients (Non-IID distribution)
✓ Client 0: ~25,000 samples
✓ Client 1: ~25,000 samples
✓ Class distribution displayed (showing Non-IID heterogeneity)
✓ Coefficient of Variation (CV) > 0.3 confirms Non-IID

EXAMPLE DATA DISTRIBUTION:
--------------------------
Client 0: 26,104 samples
  Class 0: 3128 samples (12.0%) ← More airplanes
  Class 1: 4944 samples (18.9%) ← Lots of cars
  Class 2: 2481 samples (9.5%)
  Class 6: 155 samples (0.6%)   ← Very few frogs
  Class 7: 29 samples (0.1%)    ← Almost no horses

This proves Non-IID: Each client has different class distributions!

PHASE 3: Connecting to Server
------------------------------
✓ "Connecting to server at localhost:8080..."
✓ Deprecation warnings (ignore these - they're just notices)
✓ Connection established

⏳ Client 0 will WAIT for Client 1 to connect
   You won't see any training activity until BOTH clients are connected

PHASE 4: Training Rounds
-------------------------
Once both clients connect, for EACH round (1, 2, 3):

✓ "Starting local training for round X..."
✓ Training on ~25,000 local samples
✓ Local epochs: 3
✓ Batch size: 32
✓ Progress messages during training
✓ Local model accuracy/loss displayed
✓ Sending updated weights to server
✓ Receiving new global model from server

EXAMPLE TRAINING OUTPUT:
------------------------
[Round 1] Starting local training...
Training on 26,104 samples for 3 epochs
Epoch 1/3: loss=2.1234, accuracy=0.3456
Epoch 2/3: loss=1.8765, accuracy=0.4567
Epoch 3/3: loss=1.6543, accuracy=0.5234
Local training complete. Sending weights to server...
Receiving updated global model...

PHASE 5: Completion
-------------------
After Round 3:
✓ "Training complete!"
✓ Client disconnects gracefully
✓ Terminal returns to prompt

================================================================================
KEY METRICS TO WATCH
================================================================================

1. ACCURACY PROGRESSION (Server Terminal)
------------------------------------------
Expected improvement across rounds:

Round 1: ~35-50%  (Random initialization, first learning)
Round 2: ~55-70%  (Model improving)
Round 3: ~65-80%  (Further improvement)

NOTE: With only 3 rounds, you won't reach the target 85%
      For best results, run 10 rounds

2. CLIENT DATA HETEROGENEITY (Client Terminals)
------------------------------------------------
✓ Check class distribution is DIFFERENT between clients
✓ Coefficient of Variation (CV) should be > 0.3
✓ Some classes should have very few samples (proving Non-IID)

3. MODEL AGGREGATION (Server Terminal)
---------------------------------------
✓ "Fit round X received 2 results" (confirms both clients participated)
✓ "Aggregating weights from 2 clients" (FedAvg working)

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Client says "Connection refused" or times out
SOLUTION: Make sure Server is running FIRST in Terminal 1

PROBLEM: Server says "Waiting for clients" forever
SOLUTION: Check that clients are connecting to "localhost:8080"
          Not "0.0.0.0:8080" (that won't work on Windows)

PROBLEM: Only 1 client connects, nothing happens
SOLUTION: You need BOTH clients running for training to start
          Start Terminal 3 (Client 1) to begin training

PROBLEM: Deprecation warnings about Flower
SOLUTION: These are just notices - they don't affect functionality
          Flower is moving to a new API but old one still works

================================================================================
WHAT TO DO AFTER TRAINING COMPLETES
================================================================================

1. CHECK GENERATED FILES
------------------------
Navigate to the models/ directory and verify:

models/
├── global_model.h5           ← Final aggregated model
├── model_round_1.h5          ← Checkpoint from Round 1
├── model_round_2.h5          ← Checkpoint from Round 2
├── model_round_3.h5          ← Checkpoint from Round 3
└── model_history.json        ← Training metrics (accuracy, loss)

Commands to check:
  ls models/
  cat models/model_history.json

2. VIEW TRAINING HISTORY
-------------------------
Command:
  python -c "import json; print(json.dumps(json.load(open('models/model_history.json')), indent=2))"

You'll see:
{
  "rounds": [1, 2, 3],
  "global_accuracy": [0.45, 0.68, 0.78],
  "global_loss": [1.52, 1.12, 0.89],
  "client_metrics": [...]
}

3. TEST THE TRAINED MODEL
--------------------------
Option A: Use the web interface
  python run_web.py
  Visit: http://localhost:5000
  Login: admin / admin123
  Upload a test image and see predictions

Option B: Use Python directly
  python -c "from frontend_web.inference import load_model, predict_image; model = load_model(); print(predict_image(model, 'path/to/test/image.jpg'))"

4. VIEW LOGS
------------
Check training logs:
  cat logs/training.log

5. RUN LONGER TRAINING
-----------------------
For better accuracy (85%+), run with more rounds:
  Terminal 1: python run_server.py --num-rounds 10 --min-clients 2
  Terminal 2: python run_client.py --client-id 0 --num-clients 2
  Terminal 3: python run_client.py --client-id 1 --num-clients 2

================================================================================
SUCCESS INDICATORS
================================================================================

✅ Both clients connect to server successfully
✅ Training progresses through all 3 rounds
✅ Accuracy improves from Round 1 → Round 3
✅ Models saved to models/ directory
✅ No error messages or crashes
✅ All terminals exit cleanly after Round 3
