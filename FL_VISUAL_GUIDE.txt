================================================================================
DATA FLOW PER ROUND
================================================================================

STEP 1: Server sends global model to clients
---------------------------------------------
    SERVER  ──────────────► CLIENT 0
            ──────────────► CLIENT 1

STEP 2: Clients train locally (in parallel)
--------------------------------------------
    CLIENT 0                        CLIENT 1
    ↓                               ↓
    Load local data                 Load local data
    (25K samples)                   (25K samples)
    ↓                               ↓
    Train for 3 epochs              Train for 3 epochs
    with local data                 with local data
    ↓                               ↓
    Updated model weights           Updated model weights

STEP 3: Clients send updates to server
---------------------------------------
    CLIENT 0 ──────────────► SERVER
    CLIENT 1 ──────────────► SERVER

STEP 4: Server aggregates weights (FedAvg)
-------------------------------------------
    SERVER performs weighted average:
    
    global_weights = (n₀ × weights₀ + n₁ × weights₁) / (n₀ + n₁)
    
    where:
    - n₀ = number of samples in Client 0
    - n₁ = number of samples in Client 1
    - weights₀ = Client 0's updated weights
    - weights₁ = Client 1's updated weights

STEP 5: Server evaluates and saves model
-----------------------------------------
    Evaluate on test set (10,000 samples)
    Save checkpoint: models/model_round_X.h5
    Display metrics: accuracy, loss

STEP 6: Server broadcasts updated global model
-----------------------------------------------
    SERVER  ──────────────► CLIENT 0
            ──────────────► CLIENT 1

REPEAT for next round
