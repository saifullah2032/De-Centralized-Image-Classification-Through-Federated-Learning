💡 TIPS FOR SUCCESS
================================================================================

### Maximizing Accuracy:

1. **Use Larger Model:**
   - Enhanced MobileNetV2: 75-85% (default)
   - Custom CNN: 70-80% (faster)
   - ResNet50V2: 85-92% (slower, best accuracy)

2. **Train Longer:**
   - 20 rounds: Good baseline (75-85%)
   - 30 rounds: Near optimal (85-90%)
   - 40+ rounds: Diminishing returns

3. **More Clients:**
   - 2 clients: Current setup
   - 3-4 clients: Better diversity, +3-5% accuracy
   - 5+ clients: Best performance, +5-10% accuracy

4. **Lower Learning Rate:**
   - If plateauing: Set LEARNING_RATE=0.0002
   - If oscillating: Set LEARNING_RATE=0.0001

### Troubleshooting:

**Problem:** Accuracy stuck at 60-70%
**Solution:** Train for 30 rounds or use ResNet50V2

**Problem:** Out of memory
**Solution:** Reduce BATCH_SIZE to 32 or use Custom CNN

**Problem:** Training too slow
**Solution:** Reduce LOCAL_EPOCHS to 3 or use Custom CNN

**Problem:** Loss increasing
**Solution:** Lower LEARNING_RATE to 0.0002
