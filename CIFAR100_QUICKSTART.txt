## ⚙️ CONFIGURATION OPTIONS
=================================================================================

### To Switch Back to CIFAR-10:

Edit `backend_fl/config.py`:
```python
DATASET = "CIFAR10"  # Change from CIFAR100
```

Then restart training.

---

### To Use Superclasses (20 instead of 100):

Edit `backend_fl/data_utils.py`, line 73:
```python
(X_train, y_train), (X_test, y_test) = cifar100.load_data(label_mode='coarse')
# Change 'fine' to 'coarse'
```

Then update config:
```python
NUM_CLASSES = 20  # Instead of 100
LABELS = CIFAR100_COARSE_LABELS  # Instead of CIFAR100_FINE_LABELS
```

---

### Recommended Hyperparameters for CIFAR-100:

Edit `backend_fl/config.py`:
```python
LOCAL_EPOCHS = 7           # More training (was 5)
BATCH_SIZE = 64            # Keep same
LEARNING_RATE = 0.0003     # Lower for stability (was 0.0005)
MODEL_ALPHA = 1.0          # Full capacity (keep)
```

## 💡 PRO TIPS
=================================================================================

1. **Be Patient**: CIFAR-100 is 10x harder; expect lower accuracy
2. **Train Longer**: 20-30 rounds minimum (vs 10-15 for CIFAR-10)
3. **50% is Good**: Don't expect 85%; 50-60% is excellent!
4. **Use Superclasses**: Check coarse accuracy if fine accuracy is low
5. **More Clients Help**: 3-5 clients provide more diverse data
6. **Lower Learning Rate**: If unstable, reduce to 0.0002
7. **Check Top-5**: Even if top-1 is wrong, top-5 often contains correct class

## 🐛 TROUBLESHOOTING
=================================================================================

### Problem 1: "CIFAR10_LABELS not found"
**Solution:** Restart Python/terminal to reload config

### Problem 2: Model output is 10 instead of 100
**Solution:** Delete old model: `del models/global_model.h5` and retrain

### Problem 3: Accuracy stuck at 1-5%
**Solution:** Normal for first 2-3 rounds; wait until round 5

### Problem 4: Out of memory
**Solution:** Reduce batch size to 32 in config.py

### Problem 5: Training too slow
**Solution:** Normal - 100 classes take 10-20% longer than 10 classes
